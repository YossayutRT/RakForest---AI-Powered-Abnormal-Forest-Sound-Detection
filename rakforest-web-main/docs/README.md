## เอกสารอ้างอิงเก่า

เอกสารต่อไปนี้เก็บไว้เพื่อให้เห็นแนวคิด/การหารือเดิม ไม่ใช่รายการความสามารถล่าสุดหรือข้อตกลง API ที่ยืนยันแล้ว:

- [ภาพต้นแบบ v1](mockups-v1/README.md) และ [v2](mockups-v2/README.md)
- [เอกสารหารือกลุ่มเดิม](RakForest_Team_Discussion.md) และ [ฉบับ Word](RakForest_Team_Discussion.docx)
- [ผลตรวจวันที่ 17 ตุลาคม 2569](history/verification-2026-10-17.md)
- โฟลเดอร์ [app-preview](app-preview) เป็นภาพจากการพัฒนาช่วงก่อนหน้า รูปปัจจุบันอยู่ใน `ui-accessibility/screenshots`
- [build_plan.py](build_plan.py) เป็นสคริปต์สร้างเอกสารหารือเก่า ต้องมี Python/python-docx แยกต่างหาก ไม่ใช่ส่วนที่ต้องรันเพื่อเปิดเว็บ

เมื่อข้อมูลในเอกสารเก่าต่างจากโค้ด ให้ดู README คู่มือสำหรับเพื่อนในกลุ่ม และสัญญา ML ปัจจุบันก่อน แล้วหารือกับกลุ่มเพื่อยืนยัน ไม่ใช้ข้อความเสนอในเอกสารเก่าเป็นคำสั่งเปลี่ยนระบบโดยอัตโนมัติ
