# RakForest — ภาพหน้าจอหลังปรับให้อ่านง่าย

เปิด index.html เพื่อเปรียบเทียบภาพ 9 หน้า ที่ความกว้าง 390, 768, 1366 และ 1920px ภาพทั้งหมดมาจาก browser tests ด้วยข้อมูลสาธิตและพื้นแผนที่ทดแทน ไม่ใช่แบบ Figma

หลักที่ปรับ: ข้อความหลัก 18px ปุ่ม/ช่องกรอกอย่างน้อย 16px ข้อมูลประกอบอย่างน้อย 14px เป้ากดอย่างน้อย 48px ใช้ rem และไม่ลดตัวหนังสือบนมือถือ รายการเหตุการณ์เป็นบัตรบนจอเล็ก แสดงข้อผิดพลาดใกล้ช่องกรอก พร้อมการจัดการโฟกัสคีย์บอร์ด

ทดสอบการขยายข้อความ 200% และพื้นที่จัดวาง 683 CSS px ซึ่งเทียบได้กับจอ 1366px เมื่อเบราว์เซอร์ซูม 200% ตรวจข้อความ/สถานะตัวแทนด้วยเกณฑ์ความต่างสี 4.5:1 การทดสอบนี้ไม่ใช่การรับรองการเข้าถึงครบทุกข้อหรือการทดสอบกับผู้สูงอายุจริง ควรให้เจ้าหน้าที่ทดลองงานหลักด้วยตัวเองต่อ

สร้างภาพใหม่: pnpm build แล้ว pnpm test -- tests/accessibility.spec.ts ภาพล่าสุดจะอยู่ test-results/accessibility ก่อนคัดลอกมาชุดส่งมอบนี้

## หน้าภาพรวมแบบแผนที่และแผงงาน

ภาพล่าสุดจัดแผนที่กับแผงงานข้างกันบนคอม โดยจอเล็กใช้แท็บแผนที่/รายการงาน กดตัวเลขเพื่อกรองสถานะ เลือกหมุดหรือรายการเสาเพื่อกรองงาน และเปิดรายละเอียดได้ตรงจากแผง ด้านล่างไม่มีตารางหรือกล่องกระบวนการยาวต่อกันแล้ว ภาพ Desktop หน้าภาพรวมใช้ viewport 1366×768 และ 1920×1080
