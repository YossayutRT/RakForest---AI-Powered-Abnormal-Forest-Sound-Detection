# RakForest---AI-
RakForest วิเคราะห์ไฟล์เสียงที่บันทึกจากพื้นที่ป่าด้วยเทคนิค Mel-Spectrogram ร่วมกับโมเดล CNN เพื่อจำแนกประเภทของเสียง (เสียงธรรมชาติ, เสียงเลื่อยยนต์, เสียงยานพาหนะ, เสียงปืน ฯลฯ) ช่วยให้เจ้าหน้าที่พิทักษ์ป่าตรวจพบเหตุการณ์ผิดปกติได้รวดเร็วขึ้น โดยไม่ต้องอาศัยการลาดตระเวนด้วยกำลังคนเพียงอย่างเดียว
