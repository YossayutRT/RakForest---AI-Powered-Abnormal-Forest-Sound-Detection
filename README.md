# RakForest

**ระบบตรวจจับเสียงผิดปกติในป่าด้วย AI เพื่อเฝ้าระวังการตัดไม้ทำลายป่า**

RakForest วิเคราะห์ไฟล์เสียงที่บันทึกจากพื้นที่ป่าด้วยเทคนิค Mel-Spectrogram ร่วมกับโมเดล CNN เพื่อจำแนกประเภทของเสียง (เสียงธรรมชาติ, เสียงเลื่อยยนต์, เสียงยานพาหนะ, เสียงปืน ฯลฯ) ช่วยให้เจ้าหน้าที่พิทักษ์ป่าตรวจพบเหตุการณ์ผิดปกติได้รวดเร็วขึ้น โดยไม่ต้องอาศัยการลาดตระเวนด้วยกำลังคนเพียงอย่างเดียว

---

## ปัญหาที่ต้องการแก้ไข

- พื้นที่ป่ามีขนาดกว้างและเข้าถึงยาก ทำให้จุดที่มีการตัดไม้มักเป็นจุดบอดของการตรวจจับ
- การใช้เจ้าหน้าที่ลาดตระเวนเพียงอย่างเดียวต้องใช้เวลาและกำลังคนจำนวนมาก
- การแจ้งเตือนเหตุการณ์ผิดปกติ เช่น ไฟป่า มักล่าช้าเพราะกว่าจะตรวจพบไฟก็ขยายวงกว้างแล้ว

## เป้าหมายและผลกระทบ

**กลุ่มเป้าหมาย:** เจ้าหน้าที่พิทักษ์ป่าและหน่วยงานอนุรักษ์ หน่วยงานที่ดูแลพื้นที่ป่าและอุทยาน องค์กรด้านสิ่งแวดล้อม

**Impact ที่คาดหวัง:**
- ตรวจพบเหตุการณ์ผิดปกติได้รวดเร็วขึ้น
- ช่วยระบุพื้นที่ที่ควรเข้าไปตรวจสอบ
- สนับสนุนการป้องกันไฟป่าและการทำลายป่า
- เพิ่มข้อมูลสำหรับการวางแผนดูแลพื้นที่ป่าในระยะยาว

**SDG ที่เกี่ยวข้อง:** SDG 15 — Life on Land (ป้องกันการทำลายป่าและสนับสนุนการอนุรักษ์ระบบนิเวศ)

---

## วิธีการทำงานของ AI

```
ไฟล์เสียงจากป่า → Preprocessing → Mel-Spectrogram → CNN → จำแนกประเภทเสียง → แจ้งเตือน
```

1. **Mel-Spectrogram** — แปลงไฟล์เสียงให้เป็นภาพ โดยแกนนอนคือเวลา แกนตั้งคือความถี่ และความเข้มของภาพคือระดับความดัง
2. **CNN (Convolutional Neural Network)** — เรียนรู้ pattern ของภาพ Mel-Spectrogram ที่ต่างกันในแต่ละประเภทเสียง แล้วจำแนกออกเป็นประเภทต่าง ๆ พร้อมค่าความมั่นใจ (confidence)

**หมายเหตุ:** โปรเจกต์นี้เป็น proof of concept ที่ใช้ dataset สาธารณะแทนอุปกรณ์ IoT จริงในป่า เนื่องจากยังไม่มีอุปกรณ์ติดตั้งจริง ระบบจึงทำงานแบบอัปโหลดไฟล์เสียงเข้าสู่ระบบเพื่อวิเคราะห์ แทนการรับสัญญาณจากเซนเซอร์แบบเรียลไทม์

## Data Source

| Dataset | รายละเอียด | เจ้าของข้อมูล |
|---|---|---|
| [FSC22 (IRMIOT22)](https://www.kaggle.com/datasets/irmiot22/fsc22-dataset) | เสียง 2,025 คลิป จัดหมวดหมู่เครื่องจักร สัตว์ สภาพแวดล้อม ยานพาหนะ ภัยคุกคามในป่า และเสียงมนุษย์ | Charitha Dombawala, Sandaruth Siriwardana |
| [Rainforest Connection dataset](https://huggingface.co/datasets/rfcx/frugalai) | เน้นจำแนกเสียงเครื่องตัดไม้และเสียงธรรมชาติ | Rainforest Connection (องค์กรไม่แสวงหากำไร, สหรัฐอเมริกา) |
| [Forest Sound Dataset](https://www.kaggle.com/datasets/abhyudayapokhrel/forest-sound-dataset) | เสียงทั้งปกติและผิดปกติในป่า เช่น เสียงปืน ไฟไหม้ ตัดไม้ | Abhyudaya Pokhrel |

## ฟีเจอร์หลัก

### ฝั่งเจ้าหน้าที่ (Staff Portal)
- อัปโหลดไฟล์เสียงเพื่อวิเคราะห์ด้วย AI พร้อมระบุโซนพื้นที่
- คิวตรวจสอบผลลัพธ์ที่ AI ตรวจพบความเสี่ยงสูง พร้อมยืนยัน/ปฏิเสธผล (ใช้ปรับปรุงโมเดลในอนาคต)
- ประวัติย้อนหลังพร้อมตัวกรองตามช่วงเวลา โซน และประเภทเสียง
- แจ้งเตือนอัตโนมัติเมื่อพบเสียงผิดปกติ
- Dashboard ติดตามประสิทธิภาพของโมเดล

### ฝั่งประชาชนทั่วไป (Public Portal)
- แผนที่แสดงผืนป่าอนุรักษ์สำคัญของประเทศไทย พร้อมข้อมูลทั่วไป (ประเภทป่า พื้นที่ จุดเด่นทางชีวภาพ)
- ไม่แสดงข้อมูลการตรวจจับหรือรายงานเหตุการณ์ เพื่อป้องกันการรั่วไหลของข้อมูลปฏิบัติการ
- เนื้อหาให้ความรู้เกี่ยวกับการอนุรักษ์ป่าไม้และ SDG 15

## Data Visualization

ผลลัพธ์จากโมเดล (ประเภทเสียง, เวลา, พื้นที่, ค่าความมั่นใจ) จะถูกเก็บเป็นตารางและนำไปแสดงผลใน Apache Superset เพื่อดูแนวโน้ม เช่น จำนวนเสียงแต่ละประเภท ช่วงเวลาที่พบบ่อย และพื้นที่ที่ควรเฝ้าระวัง

## Tech Stack (แผน)

- **Machine Learning:** Python, librosa, TensorFlow/PyTorch (CNN)
- **Backend:** FastAPI
- **Frontend:** React หรือ Vue, Leaflet.js (แผนที่)
- **Database:** PostgreSQL / SQLite
- **Data Visualization:** Apache Superset
